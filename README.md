## 🚀 Featured Projects

### 🎥 YouTube RAG Question-Answering System
🔗 [View Project](https://github.com/kulin-m/Youtube-rag-Q-A-system)

Designed and deployed a **production-ready RAG backend** that answers natural language questions from YouTube video transcripts with sub-15-second end-to-end latency.

- Implemented a **hybrid retrieval pipeline** combining FAISS dense vector search and BM25 sparse retrieval, fused via Reciprocal Rank Fusion (RRF), followed by a cross-encoder reranker (`ms-marco-MiniLM-L-6-v2`) and Maximal Marginal Relevance (MMR) diversity selection — achieving **Context Precision@K of 1.00** and **MRR of 1.00** across evaluation samples
- Engineered a **4-method transcript extraction fallback chain** (youtube-transcript-api → yt-dlp → Whisper ASR) enabling support for any YouTube video including uncaptioned content
- Built **7-class semantic intent detection** using Sentence-BERT with 93%+ confidence on test queries
- Exposed REST API via **FastAPI with Swagger UI** (`/docs`); evaluated across 14 metrics including Faithfulness (0.75), Answer Relevancy (0.79), Hallucination Rate (0.25), and Semantic Similarity (0.84)

**Tech:** `Python` `FastAPI` `Sentence-BERT` `FAISS` `BM25` `Gemini API` `Whisper ASR` `RAG`
